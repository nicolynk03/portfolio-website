Things I've Built

Here are some of my favourite projects that I'm currently working on or have worked on:

Completed

Honours thesis

My honours project focuses on utilising various machine learning techniques to predict total number of patient arrivals in an emergency department and further extend it to predict sub-types of patient arrivals (by ward and patient complexity) for the next day.

This project strengthened my skills in feature engineering, data pre-processing, and evaluating different machine learning approaches for healthcare forecasting problems.

Completed

iOS cricket app

As part of my undergraduate mobile application development course, I built a cricket scoring app for iOS. This project allowed me to strengthen my Swift programming skills and gain practical experience in designing user-friendly mobile applications.

Completed

Flutter cricket app

In another assignment for the same course, I developed a cricket scoring app with Flutter, focusing on cross-platform development. This project helped me understand how to design applications that run smoothly on both iOS and Android, while also deepening my knowledge of UI consistency and responsive layouts.

Ongoing Learning

EPL Winner Prediction

This is a small practice project where I further explore web scraping and machine learning techniques to predict the winner of the English Premier League (EPL). This project allowed me to strengthen my Python programming skills and gain practical experience in handling real-world sports datasets.

In a follow-up phase, I will apply machine learning techniques to predict match outcomes, focusing on feature selection, model evaluation, and predictive accuracy. This project helped me understand how to combine data collection, analysis, and modeling to derive actionable insights from a dataset.
