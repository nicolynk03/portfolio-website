# Portfolio Website Project
This repository contains the development files for my personal portfolio website. The site showcases my learning journey, highlights recent and ongoing projects, and illustrates the areas I am passionate about and interested in working on.

## Features
* Project showcase: display completed and ongoing projects.
* Learning progresses: shows skills and technolgoies I've been learning.
* Responsive design: works across desktop, tablet, and mobile devices.
* Theme support: improved user experience by including light and dark mode.

## Technologies used
* Frontend: HTML, CSS, JavaScript
* Styling: CSS variables, flexbox, responsive design
